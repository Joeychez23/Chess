# Opening names

`a.tsv` to `e.tsv` (`eco`, `name`, `pgn`) are unchanged copies from
[lichess-org/chess-openings](https://github.com/lichess-org/chess-openings), commit
`712a58be746c143f4ab935b68acc50f4bac813eb`. The data set is public domain (CC0).

`server/utils/openings.js` reads them when the server starts. To update them, download the five files again and change the commit above.
